# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/).

## [0.1.1] - 2026-06-04

### Changed

- Improved the rendered desktop layout and spacing
- Added scroll-safe window structure for compact screens
- Standardized English numeric formatting in the UI
- Improved Windows launcher scripts to prefer compatible Python versions
- Made the CI smoke test Linux-safe in headless environments
- Made the PyInstaller build output cleaner by writing spec/work files into the build directory

## [0.1.0] - 2026-06-04

### Added

- Initial public release of ClickForge
- PyQt6 desktop UI with dark and light themes
- Global hotkey support
- Toggle and hold click modes
- Cursor and fixed-position click targeting
- Session click counter and live CPS display
- Persistent local settings
- Cross-platform PyInstaller build script
