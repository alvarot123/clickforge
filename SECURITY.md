# Security Policy

## Supported versions

Only the latest published version is considered supported for security fixes.

## Reporting a vulnerability

If you discover a security issue, please do not post it publicly in a GitHub issue first.

Instead, contact the maintainers privately and include:

- A clear description of the issue
- Steps to reproduce
- Impact assessment
- Suggested mitigation, if available

The maintainers will acknowledge the report as soon as possible and work on a fix before public disclosure when appropriate.
